= 개발환경 설정(Development environment)
include::common/header.adoc[]

toc::[]

이 장에서는 {vk} 응용 프로그램을 개발하고 유용한 라이브러리를 설치할 수있는 환경을 설정합니다. 컴파일러를 제외하고 우리가 사용할 모든 도구는 Windows, Linux 및 MacOS와 호환되지만 설치 단계는 약간 다르기 때문에 여기에서 별도로 설명되어 있습니다.

== Windows

Windows용으로 개발 중인 경우 Visual Studio를 사용하여 코드를 컴파일한다고 가정합니다. 완전한 C++17 지원은 Visual Studio 2017 또는 2019를 사용해야 합니다. 아래에 설명 된 단계는 VS 2017에 대해 작성되었습니다.

=== {vk} SDK

{vk} 응용 프로그램을 개발하는 데 필요한 가장 중요한 구성 요소는 SDK입니다. 여기에는 헤더, 표준 유효성 검사 계층, 디버깅 도구 및 {vk} 함수에 대한 로더가 포함됩니다. 로더는 (만약 여러분이 OpenGL용 GLEW에 익숙하다면) 런타임에 드라이버의 기능을 찾습니다.

SDK는 페이지 하단의 버튼을 사용하여 link:https://vulkan.lunarg.com/[LunarG 웹 사이트]에서 다운로드 할 수 있습니다. 계정을 만들 필요는 없지만 유용한 추가 문서에 액세스 할 수 있습니다.

.운영체제별 {vk} SDK download 페이지
[link=https://vulkan.lunarg.com/]
image::choose_vulkan_sdk_download.png[align=center, width=80%]

설치를 통해 진행 및 SDK의 설치 위치에주의를 기울이십시오. 우리가 할 첫 번째 일은 그래픽 카드와 드라이버가 {vk}을 올바르게 지원하는지 확인하는 것입니다. SDK를 설치한 디렉터리로 이동하여 Bin 디렉터리(e.g. ##C:\>vulkan_sdk\Bin##)를 열고 vkcube.exe 데모를 실행합니다. 다음을 참조하십시오.

.vkcube.exe 실행결과
image::vkcube.exe.jpg[align=center, width=50%]

오류 메시지가 표시되면 드라이버가 최신 상태인지 확인하고 {vk} 런타임 및 그래픽 카드가 지원되는지 확인하십시오. 주요 공급 업체의 드라이버 대한 내용은 link:Introduction.adoc[소개 페이지]를 참조하십시오.

이 디렉토리(``{vk}_SDK/bin``)에는 개발에 유용한 또 다른 프로그램이 있습니다. ``glslangValidator.exe`` 및 ``glslc.exe`` 프로그램은 인간이 읽을 수있는 GLSL에서 {bytecode}로 셰이더를 컴파일하는 데 사용됩니다. link:./Drawing-a-triangle/ShaderModules.adoc:[{shdmdl}]챕터에서 이것을 자세히 다룰 것입니다. 빈 디렉터리에는 Vulkan 로더의 바이너리와 유효성 검사 계층도 포함되어 있으며 ``Lib`` 디렉터리에는 라이브러리가 포함되어 있습니다.

마지막으로 {vk} 헤더가 포함된 ``Include`` 디렉터리가 있습니다. 다른 파일을 자유롭게 탐색하십시오. 그러나이 자습서에는 필요하지 않습니다.

=== GLFW

앞서 언급했듯이 {vk} 자체는 플랫폼 독립적인 API이며 렌더링 된 결과를 표시하는 창을 만드는 도구를 포함하지 않습니다. {vk}의 크로스 플랫폼 이점과 Win32의 공포를 피하기 위해 link:http://www.glfw.org/[GLFW 라이브러리]를 사용하여 Windows, Linux 및 MacOS를 지원하는 창을 만듭니다. link:https://www.libsdl.org/[SDL]과 같이 이러한 목적으로 사용할 수 있는 다른 라이브러리가 있지만 GLFW의 장점은 창 생성 외에도 {vk}의 다른 플랫폼별 것들 중 일부를 추상화한다는 것입니다.

link:http://www.glfw.org/download.html[공식 웹 사이트]에서 GLFW의 최신 릴리스를 찾을 수 있습니다. 이 튜토리얼에서는 64 비트 바이너리를 사용할 것이지만 물론 32 비트 모드로 빌드하도록 선택할 수도 있습니다. 이 경우 ``Lib`` 대신 ``Lib32`` 디렉토리의 {vk} SDK 바이너리와 연결해야합니다. 다운로드 한 후 아카이브를 편리한 위치로 추출하십시오. 문서 아래의 Visual Studio 디렉토리에 ``Libraries`` 디렉토리를 만들기로 결정했습니다.

=== GLM

DirectX 12와 달리 Vulkan은 선형 대수학 연산을위한 라이브러리를 포함하지 않으므로 하나를 다운로드해야합니다. link:http://glm.g-truc.net/[GLM]은 그래픽 API와 함께 사용하도록 설계된 멋진 라이브러리이며 OpenGL에서도 일반적으로 사용됩니다.

GLM은 헤더 전용 라이브러리이므로 link:https://github.com/g-truc/glm/releases[최신 버전]을 다운로드하여 편리한 위치에 저장하십시오. 지금 다음과 유사한 디렉토리 구조가 있어야합니다.

=== {vs} 설정

이제 모든 종속성을 설치했으므로 Vulkan에 대한 기본 {vs} 프로젝트를 설정하고 모든 것이 작동하는지 확인하기 위해 약간의 코드를 작성할 수 있습니다.

{vs}를 시작하고 이름을 입력하고 ``확인``을 눌러 새 ``Windows Desktop Wizard`` 프로젝트를 만듭니다.

.{vs} 새 프로젝트 창
image::vs_new_cpp_project.png[align=center, width=100%]

``콘솔 응용 프로그램(.exe)``이 애플리케이션 유형으로 선택되어 디버그 메시지를 인쇄할 수 있는 장소가 있는지 확인하고, Visual Studio가 상용구 코드를 추가하는 것을 방지하기 위해 ``Empty Project``를 확인합니다.

.Empty project 선택
image::vs_application_settings.png[align=center, width=80%]

``확인``을 눌러 프로젝트를 만들고 C++ 소스 파일을 추가합니다. 당신은 이미 그것을하는 방법을 알고 있어야하지만, 단계는 완전성을 위해 여기에 포함되어 있습니다.
